# 預測系統

入口為 `/predictions`，單一預測盤為 `/predictions/:id`。所有查詢與押注須登入。

列表以「最後押注日期」篩選，預設使用者當日前後各 15 天，包含起訖兩天。日期與名稱在按下搜尋後套用，狀態選單使用 react-select；後續分頁保留已套用篩選。前端將本地起日午夜及迄日次日午夜轉成 `closesFrom`（含）與 `closesBefore`（不含）Unix 秒數，後端先篩選再分頁。

## 權限與時間

- 管理員與網頁管理員可建立、編輯、取消預測盤，於結算時間後手動公布結果。
- 管理操作即時向 Discord 驗證身份組，不信任前端或舊快取權限。
- 僅網頁管理員可添加基礎獎勵。這是系統贊助，不扣管理員餘額；只能增加。
- 選項建立後不能修改。已截止的押注時間不能重新開放。已結算或取消的預測盤不可再修改。
- 時間儲存為 Unix timestamp，依伺服器判斷截止，前端依使用者時區輸入及顯示。

## 資金規則

- 押注須為正整數且餘額足夠，立即扣款，不提供撤單。可多次押注及選擇不同選項。
- 當前賠率包含本金，為「全部下注加基礎獎勵」除以該選項下注總額；最終金額依結算時資料計算。
- 獲勝選項的下注按使用者合計，再依比例分配全池。整數採最大餘數法，同餘數按使用者 ID 字串排序，確保池額完整分配。
- 沒有對手盤且沒有基礎獎勵時，押中者領回本金；有基礎獎勵則一併按比例分配。
- 無人押中或取消時，退還所有下注，基礎獎勵不派發。
- 結算結果不可復原。任何入帳失敗會回滾整次結算，不產生部分派獎。

## 資料與稽核

首次存取自動建立 `prediction_market`、`prediction_option`、`prediction_bet`、`prediction_payout`、`prediction_event`，識別碼皆為 UUID。

帳本類型為 `prediction_bet`、`prediction_reward`、`prediction_refund`；來源分別對應下注或派款紀錄 UUID。下注、派款、選項及操作事件禁止更新或刪除。

寫入使用 SQLite 即時交易，以 UUID 操作識別碼避免重複扣款及派獎。管理編輯另有版本檢查。瀏覽器遇到無法確認的寫入結果，保留原操作供重試，不另建新扣款請求。

部署更新後仍須保留既有 SQLite 儲存掛載；本功能不需要新增環境變數。
